Exoplanet WIP README

An application that allows users to explore and analyze data about discovered exoplanets using publicly available NASA datasets. Users will be able to query exoplanets based on characteristics like size, orbital period, distance from Earth, and host star properties. The system will display results in a structured format and provide visualizations to help users understand patterns and trends. The design will be fun and interactive, targeting both children and adults trying to learn about space, and if time allows, we will integrate mini-game features.# Astro-Clicks
